# Prompts de produção · Esquadrão Sentinela, Episódio 1

Formato do episódio: **quadrinho animado**. Cada fala do roteiro mostra uma imagem aprovada, e o player faz o resto: movimento de câmera, transições, efeitos, legenda e a voz do ElevenLabs.

Tudo é gerado no **Nano Banana** (Gemini). São **29 imagens**, na ordem do roteiro. As já feitas estão marcadas ✅.

---

# PARTE 1 · NANO BANANA (imagens)

**Como fazer cada imagem:**
1. Abra o Gemini e use o gerador de imagem (Nano Banana).
2. Anexe as imagens indicadas, **na ordem** (1, 2, 3).
3. Cole o prompt.
4. Salve o resultado com o nome indicado, na pasta `referencias/cenas/`.

Algumas imagens usam como anexo outra imagem desta lista (ex.: `q_t1_06` parte de `q_t1_05`). Por isso, gere na ordem.

# Depois de gerar

1. Salve cada imagem em `referencias/cenas/` com o nome indicado.
2. Rode `npm run quadros:preparar`: ele comprime as imagens e liga cada uma na fala certa.
3. Rode `npm run dev` e assista (Personalizar → "Ir direto para um trecho").

Pode ir aos poucos: a fala que ainda não tem imagem aparece com a ilustração animada.
